# Aftermovie OMI (Remotion)

Video resumen de la experiencia vivida en las Olimpiadas Matemáticas (OMI).

👉 **Cómo montar tus videos: [GUIA-OMI.md](./GUIA-OMI.md)**

```bash
npm install
npm run dev                                       # editor visual en http://localhost:3000
npx remotion render OMI out/omi-aftermovie.mp4    # exportar el video final
```

El montaje se edita en `src/Omi/config.ts`.
